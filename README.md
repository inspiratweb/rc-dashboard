# RevenueCat Dashboard - Take-Home Test

This project is an interactive and accessible implementation of the RevenueCat Dashboard, developed as part of the Design Engineer take-home test.

🚀 **Live Demo**: [View on Vercel](https://rc-dashboard-xi.vercel.app/)

---

## 💻 Tech Stack

This project is built using modern, type-safe, and highly performant frontend tools:

* **Core Framework**: [React 19](https://react.dev) with [TypeScript 6](https://www.typescriptlang.org/) & [React Router 7](https://reactrouter.com/) (Single Page Application architecture)
* **Build System**: [Vite 8](https://vite.dev) (super-fast hot module replacement and bundle optimization)
* **Styling**: [Tailwind CSS v4](https://tailwindcss.com) (modern CSS styling engine) with [Class Variance Authority](https://cva.style/) for dynamic design system utilities
* **Data Visualization**: [Recharts 3](https://recharts.org) (accessible and responsive charts)
* **Primitives & Accessibility**: [Radix UI primitives](https://www.radix-ui.com/) (Slot for polymorphic components, Progress bar, Tooltip)

---

## ⚙️ Environment Requirements

* **Node.js**: `v20.x` or higher (LTS recommended)
* **Package Manager**: `npm` (v10.x or higher)

---

## 🛠️ Installation and Setup Steps

Follow these steps to clone and run the project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/inspiratweb/rc-dashboard.git
   cd rc-dashboard
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   The project will be available at `http://localhost:5173`.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Run the Linter**:
   ```bash
   npm run lint
   ```
